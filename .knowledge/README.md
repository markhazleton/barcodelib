# DevSpark Current Truth

This directory is the DevSpark v4 repository-owned knowledge root.

- `governance/` contains repository-wide rules and decisions.
- `entities/` contains durable metadata, including the application registry and repository configuration decisions.
- `specs/` contains feature specifications and lifecycle artifacts.
- `overrides/` contains team-level DevSpark runtime overrides.

The older `.documentation/` tree was reviewed during the v4 migration. Durable
truth belongs here; historical material may be archived after its current value
is assimilated into this tree.
